# csl-styles

## APA 7th: numeric citations, sorted by call number

[`apa-numeric-call-number.csl`](apa-numeric-call-number.csl) is a [CSL](https://citationstyles.org/) style based on APA 7th edition reference formatting, with two changes:

- **In-text citations are numbered**, like `[1]` or `[2, 5]`, instead of author-date.
- **The bibliography is sorted by call number**, the item's `Call Number` field in Zotero (for example a library classification or your own shelf or archive code). Citation numbers follow that order.

It is useful when references should line up with a physical or catalogued collection, such as library holdings, archive boxes, or a numbered sample or document set.

### Install in Zotero

1. Download the [raw file](https://raw.githubusercontent.com/Augustus-2004OKC/csl-styles/main/apa-numeric-call-number.csl).
2. In Zotero, open **Settings → Cite**, click **+**, and choose the downloaded `.csl` file.
3. Pick "APA 7th (numeric citations, sorted by call number)" in the Word, LibreOffice, or Google Docs plugin, or when creating a bibliography.

Make sure each item has its **Call Number** field filled in; items without one go to the end of the list.

It also works in other CSL-based tools such as Mendeley, Pandoc, and Juris-M.
